## Set up an iOS device with Expo Go

### Enroll | Apple Developer Program

* [here](https://developer.apple.com/programs/)

### Build Expo Go for iOS

* `npx eas-cli@latest go`

### Install TestFlight

* ways
  * [here](https://apps.apple.com/us/app/testflight/id899247664)
  * scan the QR code

1. | [App Store Connect](https://appstoreconnect.apple.com)
   * \> Expo Go app > "TestFlight" tab > add your Apple ID email -- as an -- internal tester
     * you receive an email invitation -- to -- join the TestFlight beta
     * you MUST accept the invitation
